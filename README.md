Official repository for the paper *"AgriField-40K: Adapting Vision Models to Agriculture With
Efficient Continual Pretraining"* (CVPPA Workshop @ ECCV 2026), introducing **AgriField-40K**, a
field-centric agricultural dataset built from 17 public resources, and **AgriMAE**, a
parameter-efficient continual pretraining baseline for adapting natural-image MAEs to agriculture.

> **AgriField-40K is publicly available now** — see the dataset link above. **Code and
> pretrained checkpoints are being finalized and will be released soon.** Star/watch this
> repo to be notified.
